FileApex 是面向你自己设备的本地优先文件浏览与发送工具。只需为手机、平板或电脑配对一次，之后即可通过 Wi-Fi 或以太网在它们之间浏览和移动文件。没有账号，没有云服务，没有广告，没有跟踪器，也没有数据分析。

功能：
• 在同一网络中已配对的设备之间浏览和移动文件
• 一次向多台设备发送文件和文件夹
• 通过二维码、6 位数字码或自动检测配对，可选 PIN 锁
• 公告板：向所有已配对设备发送文字消息或文件
• 可选的剪贴板共享，支持任意方向
• 可选的手机通知，显示在你的电脑上
• 设备详情：每台已配对设备的电量、存储、内存和网络
• 查找手机：让已配对的手机响铃
• Android 分享菜单中的已配对设备目标
• 后台常驻，附带电池使用指引，可选重启后自动恢复

此版本仅限本地网络。它不包含 Google 账号登录、云端在线状态、Google Drive 中继或 Tailscale 支持，也没有 Firebase 或 Google Play 服务代码。更新通过 F-Droid 提供。

Windows、macOS 和 Linux 桌面版可在项目页面获取。由于 F-Droid 使用自己的密钥为其构建签名，从 GitHub 安装的版本无法通过此版本更新：请先卸载 GitHub 版本，这会清除其配对信息。
