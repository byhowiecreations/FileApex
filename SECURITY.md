# Security Policy

## Supported Versions

Security fixes are provided for the latest release only. Please update to the
newest version of FileApex before reporting an issue.

## Reporting a Vulnerability

Please do not report security issues in public issues, discussions, or social
media.

Report privately in either of these ways:

- **GitHub:** Use "Report a vulnerability" under the repository's **Security**
  tab (private vulnerability reporting).
- **Email:** byhowiecreations@gmail.com

Please include:

- A description of the issue and its potential impact
- Steps to reproduce it
- The app version and platform (Android, Mac, Windows, Linux, Docker)

## What to Expect

- I'll acknowledge your report within 7 days.
- I'll keep you updated while I investigate and work on a fix.
- Once a fix is released, I'm happy to credit you if you'd like.

## Scope

This policy covers the FileApex app and its official Docker image. Issues in
third-party services we integrate with, such as Tailscale, should be reported
to those providers.
